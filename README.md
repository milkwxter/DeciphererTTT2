# TTT2 Role Addon: The Decipherer
A new detective subrole for your TTT2 servers, the Decipherer.

The Decipherer spawns with a new gadget instead of the DNA Scanner, called the Minitester.
This Minitester charges up while equipped, and can be used on another player to reveal their role to the Decipherer.

If the Decipherer uses the Minitester on a player belonging to the traitor team, it will self-destruct and cause a discombobulator explosion.

# Configurable Variables
This addon comes with several configurable variables the admins can change. This is only a brief overview, please check the F1 menu for more information!
- `ttt2_decipherer_max_charge` - How much charge does the minitester need to work?
- `ttt2_decipherer_start_charge_pct` - Percent of charge the minitester starts with?
- `ttt2_decipherer_max_uses_enabled` - Should the minitester have a limit to uses?
- `ttt2_decipherer_max_uses` - Max uses for minitester?
- `ttt2_decipherer_destroy_on_traitor` - Destroy minitester when revealing a traitor?
- `ttt2_decipherer_discombob_on_traitor` - Discombobulate Decipherer when revealing a traitor?
- `ttt2_decipherer_smoke_on_traitor` - Smoke bomb Decipherer when revealing a traitor?
